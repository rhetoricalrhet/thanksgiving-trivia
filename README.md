# Thanksgiving Trivia Night

A full-screen trivia game for a Thanksgiving table: six rounds (the Mayflower, 1621 myth vs. reality, how it became a holiday, the food, modern Thanksgiving, hidden gems) plus a final wager question.

Open `index.html` in any browser. No install, no account.

**Controls:** Space / → reveals the answer, then advances. ← goes back. F = full screen, H = host answer key. Keys 1–6 add a point to a team (Shift subtracts). On phones, use the on-screen buttons.

Facts were checked against Pilgrim Hall Museum, Plimoth Patuxet Museums, Smithsonian, Britannica, the White House Historical Association, USDA and similar sources.
